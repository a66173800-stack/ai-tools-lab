## 公開後の確認項目

1. トップページ、記事一覧、新規記事10本が404にならないか
2. 記事一覧の検索欄で「ロゴ」「動画」「該当なし」を試す
3. スマホ幅でメニュー・見出し・表・ボタンが画面からはみ出さないか
4. `robots.txt` と `sitemap.xml` が開けるか
5. 既存の広告リンクが変更されていないか、PR表記が明確か
6. 検索エンジン向け情報の誤りがないか
