# よりすぐりノート

仕事も暮らしも、納得して選ぶ。ジャンル横断型の比較・選び方メディア。

公開URL: https://a66173800-stack.github.io/ai-tools-lab/

静的HTML/CSSで構成。広告は承認済みのA8.net素材のみ使用。掲載内容と提携状況を継続して確認してください。

## 運用・更新手順（2026-11-02）

- 公開基盤：GitHub Pages。公開ブランチは `main`。
- 変更前の退避ブランチ：`backup-before-renewal-20261102`。復旧が必要な場合は、このブランチの内容と現在の差分を確認してから戻す。
- デザイン：`style.css`。ネイビー／ホワイト系の追加ルールはファイル末尾にまとめてある。
- 記事一覧：`categories.html`。新規記事を追加したら該当カテゴリの `article-list` にリンクを追加する。
- 記事検索：`search.js`。記事一覧のタイトルをブラウザ内で絞り込む方式。記事本文の全文検索ではない。
- サイトマップ：`sitemap.xml`。新規公開記事のURLを追加する。
- 広告：既存の `coconala.html` にA8.net広告リンクと計測画像がある。提携状況・掲載サイト・広告表示規約を確認して運用する。新規記事に広告コードを推測して追加しない。
- 新規記事10本：`coconala-*.html`（`coconala.html` は従来の記事）。公開後は公式情報との整合、出典、独自性、誤記、スマートフォン表示を確認する。
- Search Consoleのサイト所有権確認とサイトマップ送信は、サイト運営者のGoogleアカウントで行う必要がある。
- 新規記事は基本的な依頼前チェックの解説であり、実際の取引体験や検証結果を装っていない。

## 公開後の確認項目

1. トップページ、記事一覧、新規記事10本が404にならないか
2. 記事一覧の検索欄で「ロゴ」「動画」「該当なし」を試す
3. スマホ幅でメニュー・見出し・表・ボタンが画面からはみ出さないか
4. `robots.txt` と `sitemap.xml` が開けるか
5. 既存の広告リンクが変更されていないか、PR表記が明確か
6. 検索エンジン向け情報の誤りがないか
